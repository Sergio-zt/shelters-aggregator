Реальний бекенд ще не підключений. Маршрути та DTO у HTTP-клієнті — приклад, який адаптується під фактичний контракт. Пагінація, серверні фільтри / bbox, авторизація та окремий endpoint деталей потребують узгодження. Карта залишається MapLibre / OpenFreeMap. Написи самої підкладки визначає її провайдер; локалізовано інтерфейс, дані демокаталогу й керування картою.

Новий Lighthouse-аудит на цьому етапі не запускався; попередні оцінки не є виміром цієї збірки. Докладніше — `API_INTEGRATION.md` у корені.
