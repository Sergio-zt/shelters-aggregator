# Демо для команди на GitHub Pages

Окрема статична збірка: `cd frontend && npm ci && npm run build:pages`.
Результат у `frontend/dist-pages`, base `/shelters-aggregator/`.
Команда явно вмикає mock API незалежно від локального `.env.local`.
Локальна HTTP-інтеграція й звичайна production-збірка не змінюються.

Це показ інтерфейсу на 8 тестових точках: карта зовнішнього сервісу справжня,
координати й дані укриттів демонстраційні. Відгуки/пропозиції не записуються
на бекенд. Для реальних даних потрібен окремо розміщений HTTPS API.

Гілка `gh-pages` містить лише зібрані файли та `.nojekyll`.
Власник репозиторію має увімкнути Settings → Pages → Deploy from a branch →
`gh-pages` → `/ (root)` → Save.
Очікувана адреса після успішної публікації:
https://sergio-zt.github.io/shelters-aggregator/

Для оновлення: зібрати `build:pages`, клонувати тільки гілку `gh-pages` у
тимчасову папку, замінити в ній файли збірки (зберігши `.git`), додати
`.nojekyll`, зробити коміт і push. Не використовувати force-push.
Автоматичний деплой не налаштований; push вихідного коду сам по собі демо
не оновлює. Публікація не потребує мерджу незавершеної інтеграції в main.

Локально перевірено base URL, карту, іконки та відсутність помилок консолі.
